## О проекте (MVP)
Мы разработали AI-систему, которая анализирует поведение пользователя в реальном времени прямо в браузере. В отличие от жестких блокировщиков, наша система распознает **психофизиологическое состояние тильта** (потери контроля) и применяет "умные" меры сдерживания.

**Ключевые технологии:**
*   **Zero-Data Privacy:** Анализ происходит локально, данные не покидают устройство.
*   **Двухуровневый AI:** 
    1. Легковесный ML (Random Forest) для анализа биометрии мыши (50мс).
    2. Generative AI (LLM) для психологической поддержки в критические моменты.
*   **Научный подход:** Метрики основаны на критериях DSM-5 (Loss Chasing, Escalation).

## Как запустить (Инструкция для жюри)

### Шаг 1: Установка расширения
1. Скачайте этот репозиторий (Code -> Download ZIP) и распакуйте.
2. Откройте в браузере Chrome: `chrome://extensions/`
3. Включите **"Режим разработчика"** (справа сверху).
4. Нажмите **"Загрузить распакованное расширение"** и выберите папку `extension`.

### Шаг 2: Тестирование
1. Перейдите на наш тестовый стенд: [https://vivatyrdo.github.io/test-casino/](https://vivatyrdo.github.io/test-casino/)
2. Нажмите F12 (Console), чтобы видеть работу нейросети.
3. **Сценарий "Норма":** Играйте спокойно, делайте паузы. Система будет молчать.
4. **Сценарий "Тильт" (Как вызвать срабатывание):** 
   - Сделайте ставку и проиграйте.
   - **Сразу же** повысьте ставку (кнопка x2).
   - Начните быстро и хаотично кликать по кнопке "ИГРАТЬ".
   - *Результат:* Через 3-5 секунд экран заблокируется.

⚠️ **Важное примечание:** 
Для генерации текста в реальном времени расширение использует локальную нейросеть (Ollama). Если у вас не установлена Ollama, расширение будет использовать **встроенные резервные сценарии** (Fallback Mode), поэтому функционал блокировки сработает в любом случае.
