# Anti-Gambling Extension & Simulation Prototype

Симулятор онлайн-казино со встроенным модулем отслеживания поведения пользователя, предназначенный для борьбы с лудоманией (азартной зависимостью) и анализа паттернов гэмблинг-поведения.

## 🎯 Цель проекта
Разработка программного решения (расширения/инструмента), помогающего выявлять, ограничивать и предотвращать проявления гэмблинг-зависимости. Проект имитирует интерфейс и механики реальных онлайн-казино, позволяя безопасным образом тестировать алгоритмы обнаружения рискованного поведения (агрессивные ставки, удвоение после проигрыша, частота кликов).

## 💡 Ключевой функционал
* **Эмуляция интерфейса казино:** Имитация популярного онлайн-казино с интерактивными слотами (Sweet Bonanza, Aviator и др.), live-лентой выигрышей других игроков и системой депозитов.
* **Игровой движок (Slots Simulation):** Генерация случайных результатов ставок, анимация вращения спинов и динамический расчет баланса (KZT).
* **Модуль мониторинга и логирования:** Встроенный сбор метрик поведения игрока (частота ставок, изменение размера ставки после проигрыша/выигрыша) для последующего анализа алгоритмами предотвращения зависимости.
* **Интерфейс самоограничения:** Анализ триггеров лудомании (фейковые выигрыши, агрессивный маркетинг, «Catching up» механики).

## 🛠 Технологии
* **Frontend:** HTML5, CSS3 (Flexbox/Grid, анимированные эффекты), JavaScript (ES6+).
* **Хранение данных:** LocalStorage (сохранение баланса и состояния пользовательской сессии).
* **Иконки & Стили:** FontAwesome.
